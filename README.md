# CookWise

CookWise is a smart recipe and kitchen management application designed to help users organize their pantry, discover recipes, and manage their cooking experience efficiently.

The system is composed of:

- Flutter Frontend

- Node.js + Express + Mongoose Backend

- MongoDB Database

## Features
- **Pantry Management**: Users can add, update, and delete ingredients in their pantry, keeping track of what they have on hand.
- **Shopping List Management**: Users can create and manage shopping lists based on their pantry inventory and recipe needs.
- **Favorite Recipes**: Users can have favorite recipes so later on this data will be used to make good recipe recomendations for him.


## Installation

### Backend
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   npm install express mongoose cors dotenv jsonwebtoken bcryptjs
    ```

3. Start the server:
   ```bash
   node server.js
   ```

### Frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
    flutter pub get
    ```
3. Run the application:
   ```bash
    flutter run
    ```
